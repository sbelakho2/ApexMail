## Scope of this statement

This statement maps common control families to what the repository sources show today, using CC-style numbering as an internal draft convention. It is not a certification submission, not an auditor deliverable, and not a claim that any observation period has started.

Framework status remains what `docs/security/framework-status.md` records: SOC 2 Type II planned with readiness assessment Q1 2027, GDPR controls being mapped, HIPAA planned with readiness assessment Q2 2027, ISO 27001 not planned. No row below upgrades that table.

Status meanings: **Implemented** names a gate, test or runbook that enforces the family today; **Partial** names the mechanism plus what the audit backlog still lists as open; the not-applicable value states the reason from a source.
