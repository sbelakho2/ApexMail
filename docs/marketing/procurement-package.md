## Request Process

1. Contact sales@apexmail.ee with the subject "Procurement Package Request"
2. Specify which documents you need and your organization name
3. ApexMail will respond within 1 business day with the requested materials
4. For security review, specify any additional requirements (penetration test reports, architecture deep-dives, etc.)
