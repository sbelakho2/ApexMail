# Content Standards and Editorial Review

> Last updated: 2026-07-29
> Applies to all published content on apexmail.ee

## Prohibited Subjective Terms

The following terms must be removed or supported by measurable facts:

| Term | Required Replacement |
|------|---------------------|
| Enterprise-grade | Replace with specific enterprise features (e.g., "supports SAML SSO, RBAC, audit logging") |
| World-class | Remove or replace with specific achievement |
| Best-in-class | Remove or replace with objective comparison |
| Seamless | Describe the actual integration experience |
| Effortless | State the actual number of steps required |
| Powerful | Remove or replace with capability description |
| Robust | Replace with specific reliability data |
| Cutting-edge | Remove or replace with specific technology |
| Revolutionary | Remove |
| Unmatched | Remove unless substantiated by independent comparison |
| Built for scale | Replace with specific scale metrics |
| Secure by design | Replace with specific security controls |
| Developer-first | Replace with developer features (SDKs, API, CLI, docs) |
| Lightning-fast | Replace with specific performance metric |

## Product Name Standards

| Official Name | Notes |
|--------------|-------|
| ApexMail | Company/product name. Capitalize the A and M. |
| ApexMail API | The REST API product. |
| ApexMail Cloud | Shared multi-tenant cloud deployment. |
| ApexMail Private Cloud | Dedicated and BYOC deployments collectively. |
| ApexMail Enterprise | Enterprise plan and commercial offering. |
| ApexMail Dashboard | Web-based management interface. |
| Message Events | Webhook event system. |
| Dynamic Allocation | Plan boundary and overage billing model. |

Capitalization must be consistent across navigation, documentation, and billing.

## Editorial Review Checklist

Every published page must pass:

- [ ] Factual accuracy (verified against source of truth)
- [ ] Claim-register approval (all claims in claims registry)
- [ ] Legal entity identity correct (Bel Consulting OÜ)
- [ ] Pricing accuracy (matches billing system)
- [ ] Technical accuracy (reviewed by engineering)
- [ ] Terminology consistent (matches product name standards)
- [ ] Grammar and spelling
- [ ] Accessibility (WCAG 2.2 AA)
- [ ] Metadata (title, description, OG tags)
- [ ] Links (no broken links)
- [ ] Mobile layout (responsive at all breakpoints)
- [ ] CTA tracking (event names correct)
- [ ] Owner assignment (named page owner)
- [ ] Review date (visible last-updated date)

## Page Ownership

Every published page must have:
- Named owner
- Last review date
- Next review date (not exceeding 6 months)

Outdated pages (past review date) must be flagged and either reviewed or unpublished.
