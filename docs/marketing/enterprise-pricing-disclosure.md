# Enterprise Pricing Disclosure

> Last updated: 2026-07-29

## Canonical Enterprise Shared offer

Enterprise Shared starts at **EUR 3,000 per month** on an annual agreement and includes 5 million monthly emails, 10 dedicated IPs, Enterprise support, contractual SLA coverage and private-deployment assessment. Dedicated Tenant and customer-cloud deployments are separately scoped and priced.

| Parameter | Value |
|-----------|-------|
| Billing period | Monthly (annual commitment) |
| Contract minimum | 12 months |
| Included email volume | 5,000,000 recipients per month |
| Included dedicated IPs | 10 managed dedicated IPs |
| Setup fee | EUR 0 for Enterprise Shared (Dedicated Tenant and BYOC have separate one-time setup fees) |
| Migration support | Included for standard migrations |
| Support level | Email, Portal, Slack, Phone, Dedicated CSM |
| SLA | 99.9% uptime (credits apply for breaches) |
| Security review | Available on request |
| Data-residency options | EU (EEA) default; custom regions available with Private Cloud |
| Private Cloud inclusion | NOT included in the EUR 3,000 base price |
| Dedicated Tenant | Separate product from EUR 4,000/mo (EUR 10,000–40,000 one-time setup) |
| BYOC (Customer Cloud) | Separate product from EUR 6,500/mo (EUR 20,000–60,000 one-time setup) |
| Customer cloud costs | Not included for BYOC; customer pays cloud provider directly |
| Overage | EUR 0.22–EUR 0.35/1,000 emails (contractual, negotiable) |
| Professional services | Quoted separately for custom integrations, architecture reviews, etc. |
| Annual discount | 10% for annual prepayment |
| Renewal terms | Automatic renewal unless cancelled 30 days before term end |

## Important distinctions

- **Enterprise Shared** and **Private Cloud** are separate offerings. The Enterprise starting price of EUR 3,000/month does not include dedicated infrastructure, dedicated tenancy, or BYOC deployment.
- **Dedicated Tenant** (EUR 4,000/mo) and **BYOC** (EUR 6,500/mo) are separately priced products with their own one-time setup fees, minimum terms, and scope.
- Enterprise buyers understand the minimum commitment is 12 months for custom contractual terms.
- Sales proposals use this same baseline and clearly separate Enterprise Shared pricing from Private Cloud add-ons.
- Annual prepayment provides a 10% discount on the base subscription fee.

## What buyers should ask sales about

- Custom overage rates for volumes above 5,000,000/month
- Dedicated IP pool sizing for high-volume senders
- Private Cloud eligibility and regional availability
- Custom SLA terms and credits
- BAA/HIPAA review availability
- Custom data retention periods
- Dedicated Tenant setup fee scope and timeline
- BYOC deployment architecture and responsibilities
- Multi-year pricing and locked rates
