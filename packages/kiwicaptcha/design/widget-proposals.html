KiwiCaptcha — widget design proposals

Twelve directions for the widget surface, all wearing the chosen Spiral Lock mark and all retiring the shine. Every direction keeps the current contract: auto-solving PoW (status, not puzzle), aria-live status announcements, a single interactive Retry (≥44px, 2px focus ring at 3:1), motion 100–500 ms per NN/g with prefers-reduced-motion honored, themeable via CSS custom properties, zero gradients. Click a state to preview it.

Mocks are design-direction artifacts (final CSS is engineered at implementation, including the embedded no-JS fallback and locale packs).
