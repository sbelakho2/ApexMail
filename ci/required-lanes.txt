# ci/required-lanes.txt — the lanes a release blessing MUST record (T1, plan
# rule 1: "Required means recorded"). One lane id per line; blank lines and
# #-comments are ignored. A blessing whose requiredLanes map is missing a row
# for any lane here, or records it as anything other than ok, is refused by
# the deploy host (ci/lib.sh gate_blessing_refusal — which also verifies the
# blessing's HMAC signature and freshness, invariant I20).
#
# Lane ids are MECHANICAL: "<stage>.<slug>" where slug is the ci_check label
# lowercased with every non-alphanumeric run collapsed to one dash — the same
# algorithm ci/lib.sh ci_check_lane_id applies when a stage records its lanes
# into the run manifest. tools/check_waivers.py --check-lanes (the
# validate.lane-waivers lane) proves every row here names a REQUIRED-capable
# lane a stage actually runs — advisory checks are excluded because an
# advisory failure must never refuse a blessing; a row with no producing
# check fails CI.
#
# Not listed here, deliberately:
#   * validate.claim-expiry — recorded every run, but advisory by declared
#     default. (test.coverage-ratchet LEFT this list on 2026-10-30: T2 flipped
#     CI_COVERAGE_CHECK to required, so the ratchet lane now gates a blessing
#     and its row lives below. test.coverage-floors and test.fuzz-smoke are
#     the T2/T7 rows added with it.)
#   * checks with DYNAMIC labels (per-image trivy scans, the dogfood live
#     battery) — recorded with their concrete per-run ids;
#   * deploy-line stages (images/migrate/deploy/verify/notify) — verified by
#     .gate-blessing.json membership, not this ledger.
#
# REGENERATION: the lane rows below are generated from the stage sources —
# for every stage on the CI_STAGES line (ci/pipeline.conf), collect the
# REQUIRED-capable labels with the same scanner tools/check_waivers.py uses
# (stage_slug_set: ci_check labels, required ci_lane_record ids, docs/ui
# gates, _mv_gate without `advisory`), slugify, sort, and emit one
# <stage>.<slug> row per section. Never hand-add a row a stage cannot
# produce; tools/check_waivers.py --check-lanes fails the run on one.
#
