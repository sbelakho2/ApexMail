// Server-side send example
const response = await fetch('https://api.apexmail.ee/v1/messages', {
  method: 'POST',
  headers: {
    'X-API-Key': process.env.APEXMAIL_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    from: 'hello@yourcompany.com',
    to: 'customer@example.com',
    subject: 'Welcome to Our Platform!',
    html: '<h1>Hello World!</h1>',
    type: 'transactional'
  })
});
// That's it. Email delivered with full tracking.
console.log(await response.json());
// { id: "msg_abc123", status: "queued" }

Architecture de sécurité

Une sécurité qui satisfait
les audits les plus rigoureux.

Sécurité de niveau entreprise intégrée à chaque couche. Du chiffrement matériel aux journaux d'audit déterministes.

  • Contrôles de sécurité entreprise

    Des fonctions de sécurité et d'audit sont disponibles selon le forfait ; la certification SOC 2 n'est pas actuellement proposée.

  • RGPD et statut de conformité

    Traitement orienté RGPD dans les centres de données de l'UE. La disponibilité HIPAA n'est pas actuellement proposée.

  • Chiffrement AES-256

    Toutes les données chiffrées au repos et en transit via TLS 1.2+ (TLS 1.3 préféré).

  • Piste d'Audit Complète

    Journalisation d'audit avec vérification d'intégrité.
