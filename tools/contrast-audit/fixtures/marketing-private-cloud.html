Enterprise-Grade Security Isolation

Dedicated deployment options can isolate email infrastructure, encryption boundaries, and monitoring paths based on a scoped architecture review.

Network Isolation

Dedicated VPC, private subnet, NACL, and security group patterns can be included when required by the deployment design.

Encryption at Rest

AES-256 encryption for stored data, with customer-managed key options reviewed for dedicated deployments.

Encryption in Transit

TLS 1.2+ enforced, TLS 1.3 preferred on all connections. Opportunistic DANE and MTA-STS for outbound delivery.

Access Control

SSO/SAML integration, role-based access, IP allowlisting, and mandatory 2FA for all admin operations.

Audit Logging

Audit logs for API, configuration, and admin events with export workflows for security review.

Compliance Controls

GDPR-oriented workflows and audit-capable plans are available. HIPAA availability and SOC 2 certification are not currently offered.
