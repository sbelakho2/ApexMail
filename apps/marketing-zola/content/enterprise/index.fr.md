## ApexMail Enterprise

Enterprise est une offre contractuelle de livraison d'emails pour les organisations qui ont besoin d'une revue commerciale, de sécurité ou de déploiement au-delà des forfaits self-service publics.

## Droits du catalogue

| Élément | Enterprise Cloud |
|---|---|
| Prix | à partir de €1,750/mois dans le cadre d'un contrat annuel |
| Volume d'emails inclus | 5,000,000 emails/mois |
| Appels API | Illimités |
| Domaines et membres d'équipe | Illimités |
| Rétention | 730 jours |
| IP dédiées | 3 incluses |
| Contrôles d'accès | SAML SSO et journaux d'audit |
| Niveau de support | Dédié |
| Cloud Privé / BYOIP | Soumis à revue contractuelle et technique |

Le prix catalogue est de à partir de €1,750/mois (€17,500/an). Les coûts personnalisés de volume, de déploiement et de services professionnels sont négociés et indiqués uniquement dans une proposition écrite ou un bon de commande.

## Revue d'achat

Un acheteur qualifié peut demander la DPA actuelle, les informations sur les sous-traitants, la présentation de sécurité, la documentation d'architecture et les conditions de service applicables. La facturation, les bons de commande ou d'autres modalités de paiement ne sont disponibles que si elles sont approuvées au contrat.

## Sécurité et conformité

- ApexMail prend en charge la documentation de traitement orientée RGPD et propose une DPA à examiner.
- La disponibilité HIPAA et une BAA ne sont **pas proposées actuellement**.
- Tout SLA, périmètre de résidence des données, réponse à un questionnaire de sécurité ou engagement de déploiement privé est régi par l'accord signé.

## Souveraineté européenne

Enterprise Cloud inclut le routage EU-only : chaque envoi ne part que par les MTA européens propres d'ApexMail, avec une retenue fail-closed au lieu d'un repli tiers, et chaque message accepté porte un reçu de routage signé Ed25519. L'argument complet — société de l'UE, centres de données européens, le mode de routage et les reçus, chacun lié à sa preuve — se trouve sur la [page de souveraineté européenne](/fr/eu-sovereign/).

## Cycle de facturation

Enterprise n'est pas achetable via le Checkout public générique. Le contrat ou l'arrangement de facturation approuvé fait foi pour les droits. Pour les forfaits self-service publics, un paiement Mollie réglé est requis avant l'octroi d'un forfait payant. Mollie ne transmet qu'un id au webhook ; ApexMail récupère et vérifie donc le paiement avec sa clé d'API.

### Prestataire de paiement

Mollie B.V. est un établissement de paiement supervisé par De Nederlandsche Bank (DNB), dont le siège social est situé Keizersgracht 126, 1015 CW Amsterdam, Pays-Bas. Les données de paiement sont traitées aux Pays-Bas (UE) ; les réseaux de cartes peuvent les traiter à l'échelle mondiale dans le cadre de l'accord de traitement des données de Mollie.
