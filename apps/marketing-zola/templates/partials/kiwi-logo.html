{# ── ApexMail Kiwi Logo Lockup ────────────────────────────────────────── #} {# #} {# The horizontal brand lockup: kiwi mark (inline SVG) + "ApexMail" #} {# wordmark. Used in the header and footer. The mark uses currentColor so #} {# it inherits the surrounding text color and the brand accent naturally; #} {# this also makes dark-mode automatic without per-variant assets. #} {# #} {# Variable: #} {# - mark_size: height of the kiwi mark in px (default 32). The wordmark #} {# scales with it. #} {# #} {# Design notes: #} {# - The mark carried here is the FULL version (eye + legs), intended #} {# for display sizes >= 24px. The simplified favicon-only variant #} {# (beak + body, no detail) lives in static/icon.svg and is what #} {# base.html loads via . This split follows the #} {# Smashing Magazine responsive-logo guidance: design favicon-first, #} {# then add detail for contexts where it survives. #} {# - The kiwi is INDEPENDENT artwork — it shares nothing with the #} {# KiwiCaptcha package's own logo helpers. Enforced by #} {# tools/check-kiwi-marketing-isolation.sh. See marketing_audit v2 §6.#} {# #} {# Brand clear-space rule (GitLab/Slab convention): the gap between the #} {# mark and the wordmark equals the x-height of the wordmark; surrounding #} {# clear space is 1x the mark height. The `gap-2.5` (10px) implements the #} {# first at the default 32px mark size. #} {% set mark_size = mark_size | default(value=32) %} {# Kiwi mark — full variant with eye + legs. currentColor lets it inherit #} {# text-brand-600 from the parent so it tracks the brand accent and dark #} {# mode without separate dark variants. #} {# Wordmark — "Apex" in the brand accent, "Mail" in the foreground. The #} {# text-surface-950 on "Mail" is auto-inverted in dark mode by the #} {# html.dark { --surface-950: ... } override in input.css (the project's #} {# documented dark-mode mechanism — no Tailwind dark: variant needed). #} {# Sized in SVG user units (font-size="20" inside a 40-unit-tall viewBox, #} {# matching the kiwi_lockup pattern) so the type scales with the viewBox #} {# instead of an inherited em. Rendered height = mark_size * 1.25, so #} {# the wordmark font-size resolves to 0.625 * mark_size px (20px at the #} {# default 32px mark) at every scale. #} {# Geometry: baseline y=27 with font-size 20 → Inter cap-height ≈ 0.727em #} {# ≈ 14.5 units; cap band 12.5→27 centers at ≈19.7 ≈ viewBox mid (20), #} {# so the wordmark optically centers against the flex-centered mark, and #} {# cap-height ≈ 14.5px ≈ 0.45 × the 32px mark ≈ half the mark height. #}
