Journal

The legal copy of inbound and outbound messages for workspace mailboxes with archive + journaling enabled.

How journaling works

When the Mailboxes archive + journaling add-on is active, for the workspace or for an individual mailbox, every inbound delivery and every outbound send writes one immutable copy here, including the complete raw message. Disabling the add-on stops new copies; entries already written stay readable. Only workspace administrators can open this page.
