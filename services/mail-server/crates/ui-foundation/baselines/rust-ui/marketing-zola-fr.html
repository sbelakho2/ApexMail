Localisation et preuves

Européen par construction.

ApexMail est conçu en Europe et ses fonctions de souveraineté sont liées à leurs preuves, pas à des adjectifs. La livraison globale est le mode par défaut ; le routage EU-only est le réglage qui retire le transport tiers.

Scope

Périmètre honnête : la livraison globale par défaut passe par AWS SES dans sa région UE (Irlande) — une région UE d’une société américaine. Le routage EU-only la retire ; la comparaison complète figure sur la page souveraineté.
